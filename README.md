## A straightforward metaverse client in godot
The goal of this project is to create a simple, straightforward UI for metaverse clients. This uses [gdext](https://github.com/godot-rust/gdext) to interface with the rust backend, which uses [metaverse_client](https://github.com/benthic-mmo/metaverse_client) for its core server IO. 

## Getting Started 
in metaverse_godot, run
``cargo build``
This will create the binaries that godot will use to communicate with the server.
